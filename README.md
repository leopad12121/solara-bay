Solara Bay is an original open-world crime game that plays offline in a desktop browser: explore a sun-soaked coastal city on foot and by car, steal rides from the traffic, outrun the Bay PD under a five-star wanted level, and take jobs from fixer Rico Delgado — getaway runs, dockside deliveries and taxi fares that pay more every round — with traffic, pedestrians, cash pickups, a live minimap, procedural sound and a save that remembers your cash.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests, no install: `game/` is plain static files.
